# Installation Instructions

This package contains the canonical Brave Hearts Publishing content-production workflow, including the Claude Cowork photo-sourcing and license-verification stage.

**Current version: 1.2.** The active pilot is simplified to one article
at a time, one Pinterest pin per article, and one hero crop adapted from
the same visual concept — see the PILOT LIMITS section and v1.2 changelog
entry in `BHP_CONTENT_OPERATING_SYSTEM.md` for the full, binding detail.
The v1.0/v1.1 four-Pinterest-variant and weekly-cadence targets are
retained in that document as historical context only and are not the
current instruction.

## Files

- `BHP_CONTENT_OPERATING_SYSTEM.md`
- `BHP_CONTENT_TEMPLATES.md`
- `BHP_CLAUDE_CHATGPT_BOOTSTRAP.md`

## Install for Claude Code

Place all three files in:

`C:\BHP\brave-hearts-theme\docs\content-operations\`

Then follow the bootstrap file to update:

- `C:\BHP\brave-hearts-theme\CLAUDE.md`
- `C:\BHP\brave-hearts-seo-engine\CLAUDE.md`

Commit and push the theme-repo files. The SEO-engine may commit only its CLAUDE.md reference; do not duplicate an editable workflow copy there.

## Install for ChatGPT

Upload all three markdown files to ChatGPT File Library.

Use the operating system as the canonical workflow in future Brave Hearts chats.
